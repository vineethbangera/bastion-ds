# Button usage

Buttons start an action. If clicking takes the user somewhere else, it's a link: use `variant="link"`, or `asChild` with an `<a>`.

<Canvas of={ButtonStories.AllVariants} />

## Choosing a variant

| Variant | Use for |
|---|---|
| `default` | The main action in an area. One per card, dialog or toolbar. |
| `outline` | Secondary actions next to a default button, such as Cancel or Export. |
| `secondary` / `ghost` | Low-emphasis or repeated actions, such as row actions in a table. |
| `destructive` | Actions that delete data or cut off access. Confirm first. |
| `link` | Inline navigation inside text. |
