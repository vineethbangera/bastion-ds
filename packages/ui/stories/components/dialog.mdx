# Dialog usage

A dialog interrupts the user to ask for a decision or focused input. Radix handles focus, Escape and scroll lock. You're responsible for the content.

<Canvas of={DialogStories.Closed} />

Always include a `DialogTitle`. Include a `DialogDescription` unless the title says everything. Screen readers announce both when the dialog opens. For destructive confirmations, see **Patterns › Confirm destructive action**.
