# SeverityBadge usage

Shows how serious a finding, alert or vulnerability is. Every level has its own icon shape and label, so it reads without colour: for colour-blind analysts, in greyscale screenshots and on printed reports. The label can't be changed or hidden, by design.

<Canvas of={SeverityBadgeStories.AllSeverities} />

| Severity | Meaning in Sentinel |
|---|---|
| `critical` | Being exploited, or trivially exploitable. Act now. |
| `high` | Serious exposure. Fix this cycle. |
| `medium` | Real but limited risk. Schedule a fix. |
| `low` | Hardening or hygiene. |
| `info` | No risk. Context worth knowing. |
