# DataTable usage

A table for lists of records such as findings, hosts or agents. It has three slots, and your app handles the data:

- **`toolbar`**: filters, search and bulk actions above the table.
- **`rowActions(row)`**: actions for one row, in a right-hand column.
- **`emptyState`**: what to show when there are no rows.

Sorting, filtering and paging are up to your app: change `data` and the table re-renders. For a complete example, see **Patterns › Findings table**.
